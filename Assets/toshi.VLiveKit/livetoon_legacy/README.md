# VLive Live Toon Legacy

This folder is a side-by-side snapshot of `Assets/toshi.VLiveKit/livetoon` from commit `411131ffd64863e66531960cf47656823bd3b932`.

It is kept as a legacy reference for the LoadModel-style VRM 0.x / MToon conversion baseline. Unity GUIDs, shader paths, package name, asmdef names, and the legacy converter menu path were renamed so this copy can live next to the current LiveToon sources without colliding.
